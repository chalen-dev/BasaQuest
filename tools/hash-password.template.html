Make a password hash

Type a password here and send the hash instead of the password. It never leaves this page.

Send it privately, not in a public channel. A hash can't be turned back into a password, but anyone holding it can try guesses offline, so use a long, unique password. Keep your password somewhere safe: there is no way to recover it from the hash.

Same method as npm run hash-password: bcrypt, strength 12, the same library (bcryptjs __BCRYPT_VERSION__). You can turn off your internet before using this page.
